# Data distribution and minimization review

Reviewed on 2026-10-06 for the current main Figures 1–5. **Git is the only public distribution location.** The authors retain request-only inputs on Box and/or Biowulf; neither is a public download service for this project. No upload, Git operation, Box permission change or Biowulf access change is performed by this package.

## File-level decisions

The complete review covers all 169 previous inputs. There are now **105 active files: 70 Git inputs and 35 author-request inputs**. The other 64 files were unused, superseded, duplicated or regenerated by the current figure pipeline. Stable input IDs are retained, so gaps in numbering are intentional.

| Classification | Route | Meaning |
|---|---|---|
| `git_figure_support_aggregate` | `data/processed/files/` | Cohort summaries, test/model results, figure geometry and group-level event definitions intrinsic to the manuscript figures; no individual participant records are included in these files. |
| `git_project_style` | `data/processed/files/` | Plot colors; no human data. |
| `request_measured_data` | `data/external/files/`, ignored by Git | Minimal clinical/molecular measurements, feature calls, detailed timing values or required ancestry covariates. Explicit open-redistribution evidence for these custom derived tables was not established. |
| `request_reference_provenance` | `data/external/files/`, ignored by Git | The one CIC gene interval used in Figure 2. The upstream annotation release/licensing provenance was not established; the much larger annotation object is no longer distributed. |
| `excluded_unused` | Not in the active package | Retired material, preserved only in the authors' local pre-review snapshot. |

[redistribution_audit.tsv](../data/redistribution_audit.tsv) gives one decision for every original file, with its source-relative path, classification, rationale, consumer, transformation, original/current hashes and sizes. [column_audit.tsv](../data/column_audit.tsv) identifies retained and removed fields. [input_review.json](../data/input_review.json) is the machine-readable routing and transformation specification. Source-relative paths describe lineage within the original analysis; they are not download URLs or evidence of open access.

These are operational distribution decisions under the author's instruction to prepare a Git companion to the manuscript. They are not a blanket certification of study-specific NIH/DAC permissions. No study-specific data-use certification, approved research-use statement or explicit authorization to publicly redistribute the custom individual-level inputs was available in the inspected package. Such inputs therefore remain request-only; that decision does not assert that every one of them is legally controlled-access. The Git set is limited to intrinsic figure-support results, not a general-purpose individual-genome resource.

## Evidence used

- The [NCI GDC access description](https://gdc.cancer.gov/access-data/data-access-processes-and-tools) distinguishes open high-level/clinical data from controlled sequence, germline and other identifying data. A TCGA identifier by itself does not establish a file's access class.
- [GDC processing documentation](https://gdc.cancer.gov/about-data/gdc-data-processing/genomic-data-processing) distinguishes filtered open somatic MAFs from unfiltered controlled MAFs. These custom WGS-derived tables cannot be assigned the access status of a different GDC product without matching provenance.
- [GDC access policies](https://gdc.cancer.gov/access-data/data-access-policies) describe acknowledgement and dataset-specific access/use requirements. Public availability of some source data is not a source-level clearance record for every derivative here.
- [NHGRI summary-results guidance](https://www.genome.gov/about-nhgri/Policies-Guidance/Data-Sharing-Policies-and-Expectations/GSR-update-FAQs) distinguishes publication-support findings from broader online dissemination of genomic summary resources. The Git classifications here apply to the manuscript's figure support; they do not confer new rights or replace applicable institutional/source terms.

The code also checks that Git data contain no individual-record columns or TCGA participant/sample identifiers. This is a supporting technical check, not proof of anonymity or a substitute for provenance review. Detailed segment-level timing curves remain request-only even where they have no explicit identifiers.

## What was reduced

- Removed **64 unused inputs**, including the older Figure 5 release, unused model matrices/reference files, duplicate figure inputs and drawing metadata regenerated by the current code.
- Removed **416 columns from retained tables**. Survival inputs now retain the analysis variables and patient key, without file paths/sizes, redundant demographics, unrelated clinical history or duplicate survival fields. Required ancestry PC covariates stay in the private Cox inputs.
- Removed feature-file links, run/sample metadata paths, software-output links and unused classification metadata from the AC2 inputs. Classification, filter status, gene lists, specimen/patient keys, copy number and context used by the calculations are retained.
- Reduced the RNA metadata, Figure 3 matrix tables, chronology tables and TP53 inputs to the required measurements, display fields and linkage keys. Variant identity and selection-depth/VAF metadata unused by the TP53 regression were removed.
- Reduced three specimen-linked ordering-event tables to unique group-level event definitions. Patient identifiers and individual copy-number states were removed; interval overlap and event selection still reproduce exactly.
- Retained only the displayed multinomial test row and the two primary survival analyses in the saved regression-reference tables. This does not change the tested models or correction families.
- Removed unused GSEA leading-edge gene lists; displayed enrichment statistics and pathway labels are retained.
- Replaced the full gene annotation RData object with a one-row CIC coordinate table, checked against the original object. No new reference release or genome build was substituted.

Retained numeric cell strings and relative row order are preserved during projection, filtering and deduplication. Cohort selection, values, transformations, statistical methods, correction families and drawing styles are unchanged. Original project files outside this standalone folder are untouched. The pre-review archives and migration sources are under ignored `.local/data_release/`.

The resulting compressed input files total **16.09 MB**: **15.33 MB in Git** and **0.763 MB by author request**. The former external files totaled 8.51 MB; the smaller request set reflects both minimization and moving reviewed aggregate results into Git. The private archive itself is about 0.764 MB, including archive overhead.

## Obtaining the request-only inputs

A Git checkout includes code, aggregate inputs, figure reports, reference artwork and the complete public input manifest. **A full recalculation of Figures 1–5 also requires the author-request bundle.** There is no substitute public Box/Biowulf URL, automatic remote download or planned public external accession.

Contact the corresponding authors listed in the manuscript. Identify this repository revision and data revision `main-figures-1-5-data-review-v1`, and describe the intended use and requested inputs. The authors determine whether and how the requested data can be supplied under applicable source and institutional permissions. A request does not itself authorize access or transfer. For controlled source data, recipients may need their own applicable authorization.

The authors' local transfer archive is `.local/bundles/panglioma-request-data.tar.gz`. It is **not part of the Git/code archive and must not be uploaded to Git**. The authors maintain their own Box/Biowulf copies; this task has not transferred the archive to either system. Use the extraction and checksum instructions in [data/external/README.md](../data/external/README.md).

## Export checks

`functions/python/package.py` checks the reviewed classifications and schemas, rejects unreviewed files in the data directories, and includes only manifest-listed Git data in the code archive. The public-input check can run without the private bundle:

```sh
python3 functions/python/run.py --check-public-inputs
```

The seven release-contract tests cover participant identifiers in generic fields, individual-record columns without barcodes, unreviewed/retired entries, unauthorized changes to a file's route, stray files and a Git-only check with private inputs absent. The full figure/statistical tests establish that minimization preserves the previous validated outputs. Results are recorded in [data_minimization_checks.json](data_minimization_checks.json) and [VALIDATION.md](VALIDATION.md).
